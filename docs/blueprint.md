# **App Name**: GastronomeAI

## Core Features:

- QR Code Menu: Generate a QR code that clients can scan to view the restaurant's digital menu on their phones.
- Real-time Order Management: Enable the kitchen and cashier to receive and manage orders in real-time.
- Inventory Tracking: Track product inventory levels and get alerts when thresholds are reached to ensure the restaurant is always stocked.
- Customer Loyalty Program: Allow customers to earn loyalty points based on their phone number and spending habits, redeemable for rewards.
- Sales Analytics Dashboard: Provide a dashboard to view sales, manage staff, track inventory, and configure loyalty programs.
- Intelligent Recipe Tool: The app will use reasoning to incorporate available ingredients, dietary restrictions, and customer preferences, if known, when creating recommendations or dynamically adjusting portion sizes to reduce waste.
- Customer Segmentation: AI-powered segmentation to identify customer groups based on dining habits. Uses tool reasoning to send targeted offers and menu recommendations.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) for a sophisticated and calming atmosphere.
- Background color: Light grey (#F0F0F0) for a clean and modern look.
- Accent color: Muted berry (#A959A7) to highlight important actions and elements.
- Body font: 'PT Sans' for a modern, readable feel.
- Headline font: 'Playfair' for elegance and readability.
- Simple, clean icons to represent menu categories and actions.
- Mobile-first, PWA-optimized layout that is responsive and intuitive on any device.
- Subtle animations on button hovers and transitions to give the app a modern feel.
